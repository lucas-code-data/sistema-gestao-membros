# Sistema de Gestão de Membros

## 📖 Sobre o projeto

Este é o meu primeiro projeto utilizando Python e MySQL, desenvolvido como parte dos meus estudos de programação.

O sistema permite realizar o cadastro e gerenciamento de membros por meio de um menu interativo no terminal.

## 🚀 Funcionalidades

- Cadastro de novos membros
- Listagem de todos os membros cadastrados
- Busca de membros por ID
- Estatísticas do sistema
  - Total de funcionários
  - Folha de pagamento
  - Média salarial
  - Divisão por gênero
  - Funcionário mais antigo

## 🛠️ Tecnologias utilizadas

- Python
- MySQL
- Git
- GitHub
